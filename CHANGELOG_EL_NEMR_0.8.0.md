# El-Nemr Language 0.8.0

## New youthful GUI + branding
- Product branding changed to **El-Nemr Language** on Android and iOS.
- In-app lockup includes **made by Dr Mustafa Salah El-Nemr** below the logo.
- New navy/cyan/violet Material 3 theme with larger rounded cards/chips and neon accents.
- Launcher icons refreshed to remove the old DreamPlayer wordmark.
- Android TV banner refreshed to El-Nemr Language.
- Native playback/download notifications now use the El-Nemr Language name.

## Navigation
The root navigation now has five destinations:
1. Home
2. Discover
3. Search
4. Local
5. Profile

## Search
- Dedicated global Search screen.
- Search across Movies, Series & TV, Sports & matches, Documentaries, News, Kids and Learning.
- Search includes all languages but keeps the learner's target language ranked first.
- Different-language video warning preserves the learner's target language and allows Play anyway.

## Local
- Open Files.
- Import Video (iOS Files picker; Android file browser).
- Scan Device on Android using the existing native MediaStore scanner.
- Recent local videos with resume time.
- Auto Search Subtitles toggle wired directly to the player's `SubtitlePrefs` setting.
- Auto subtitle search defaults ON for new installs; it queries online only when the configured subtitle provider/API is available.

## Compatibility
- Android minimum remains API 26 / Android 8.0.
- Existing learning, multi-subtitle, discovery and recommendation features from 0.7.0 are retained.
